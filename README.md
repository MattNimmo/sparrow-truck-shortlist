# Sparrow live truck comparison

Public comparison for the ten selected trucks. Saved public listing details are fetched from the dedicated read-only feed every15seconds while the tab is visible. No API key, database credentials or direct table access is present in the site. No VINs, private evaluation records, internal IDs or additional ledger candidates are exposed.

The original curated order is retained. Proposed weighted scoring is not implemented. Each row shows the source observation time; disconnected pages retain the last good data with an explicit warning. Source scans retain their1PM America/Chicago Sunday–Friday schedule. Saved data refresh does not mean continuous source verification.

Run `npm test`. Serve the root on http://127.0.0.1:8771 for the allowed local preview. Deploy main to GitHub Pages. The dated inline HTML is fallback content only until the feed connects.
